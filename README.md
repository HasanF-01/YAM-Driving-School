كل اختبار يختار **30 سؤالاً عشوائياً**، والنجاح يتطلب **24/30**.

## التنقّل بين الأسئلة

- زرّا **السابق / التالي** أسفل الشاشة للتنقّل بالترتيب.
- **شريط أرقام الأسئلة** أعلى السؤال: اضغط أي رقم للانتقال مباشرة إليه.
  - أخضر = أجبت صح، أحمر = أجبت خطأ، إطار متقطّع = اخترت إجابة ولم تؤكّدها بعد، أزرق = السؤال الحالي.
- يمكن تخطّي سؤال والرجوع إليه لاحقاً؛ الاختيار غير المؤكّد يبقى محفوظاً.
- السؤال المؤكَّد يبقى ظاهراً بإجابته الصحيحة عند الرجوع إليه ولا يمكن تغييره.
- في السؤال الأخير يتحوّل زر التالي إلى **إنهاء الاختبار**، مع تنبيه إذا بقيت أسئلة بدون إجابة.
- على الكمبيوتر: السهم ← للسؤال التالي، والسهم → للسؤال السابق.
- شريط التقدّم يعبّر عن **عدد الأسئلة المُجابة** من أصل 30.

## ⚠️ الشعار — الخطوة الوحيدة الناقصة

ضع صورة الشعار الأصلية هنا:

```
assets/logo.png
```

- يُفضّل **قصّ الفراغ الأبيض** حول الشعار قبل الحفظ (الصورة الأصلية فيها هوامش بيضاء كبيرة).
- الأفضل أن تكون بخلفية شفافة (PNG) وبعرض ~800px.
- إلى أن تضعها، يعرض الموقع نسخة SVG بديلة (`assets/logo.svg`) مرسومة لتشبه الشعار.
- صفحات الاختبار تستعمل `assets/logo-mark.svg` (شعار مصغّر YAM فقط) لأنه أوضح بالحجم الصغير.

## التشغيل محلياً

الملفات تحتاج خادم (بسبب `fetch` لملفات JSON) — الفتح المباشر بالنقر المزدوج لن يعمل:

```powershell
# باستخدام Node
node -e "require('http').createServer((q,s)=>{const p=require('path').join(__dirname,q.url==='/'?'index.html':q.url.split('?')[0]);require('fs').readFile(p,(e,d)=>e?s.writeHead(404).end():s.end(d))}).listen(8777)"
```

ثم افتح: `http://localhost:8777`

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع كل محتويات هذا المجلد إلى الفرع `main`.
3. Settings → Pages → Source: `main` / `(root)` → Save.
4. الرابط سيصبح: `https://<username>.github.io/<repo>/`

## تعديل الأسئلة

كل ملف JSON عبارة عن مصفوفة بهذا الشكل:

```json
{
  "id": 1,
  "question": "نص السؤال",
  "image": "assets/signs/sign-000.png",
  "choices": ["الخيار الأول", "الخيار الثاني", "الخيار الثالث"],
  "correctIndex": 0
}
```

- `image` اختياري (احذفه أو اتركه فارغاً للأسئلة النصية).
- `correctIndex` يبدأ من **0**.
